
# EE331 Signals and Systems Homework

This project was prepared for the EE331 Signals and Systems course. The main goal of the assignment is to analyze a real audio recording of musical notes in both time and frequency domains, estimate the fundamental frequencies of the notes, and design a digital filter to isolate a selected note. The homework also includes a simple MATLAB GUI for loading audio, visualizing signals, applying filters, and playing the original/filtered sounds. :contentReference[oaicite:0]{index=0}

## What I Did

- Recorded a sequence of at least 8 musical notes using a smartphone.
- Loaded the audio file into MATLAB and analyzed its sampling frequency and duration.
- Plotted the recorded signal in the time domain.
- Divided the recording into note segments.
- Applied FFT to each note segment to observe the frequency spectrum.
- Estimated the fundamental frequency of each note.
- Compared measured frequencies with theoretical musical note frequencies.
- Designed a band-pass filter to isolate a selected target note.
- Applied the filter to the full recording and compared original vs. filtered signals.
- Created a MATLAB GUI to load audio, display plots, adjust filter parameters, and play both original and filtered audio.

## Tools Used

- MATLAB
- FFT analysis
- Digital band-pass filtering
- MATLAB GUI/App Designer
- Smartphone audio recording

## Purpose

This project demonstrates basic signal processing concepts such as time-domain analysis, frequency-domain analysis, Fourier Transform, musical note frequency estimation, and digital filter design using a real-world audio signal.
