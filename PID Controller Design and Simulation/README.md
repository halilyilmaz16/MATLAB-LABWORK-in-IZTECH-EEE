# PID Controller Design and Simulation

This repository contains a CENG 424 assignment focused on designing a PID controller to control the position of a servo motor.

The system was modeled and simulated in Simulink. The PID controller was tuned and evaluated based on position accuracy and response time.

## Contents

- MATLAB parameter script
- Simulink model
- Simulation results
- Scope plots
- Performance evaluation report

## Goal

The main goal of this assignment is to design, simulate, and evaluate a PID controller for servo motor position control.
